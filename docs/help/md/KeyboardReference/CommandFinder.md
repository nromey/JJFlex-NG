# Command Finder

Use the Command Finder to look up a keyboard command or a shortcut you have forgotten. It gives you a searchable list of every keyboard command in JJ Flexible Radio Access.

## Opening Command Finder

Press `Ctrl+/` from anywhere in the application to open the Command Finder. Focus starts in the search box, so you can begin typing the command you want.

## How It Works

Three controls at the top help you narrow the list:

1. **Category filter:** Choose a category such as Tuning, DSP, Audio, or Slices. Choose "All" to include every category.
2. **Search box:** Type a word or phrase to search within the selected category. For example, choose DSP and type "noise" to find the noise-related DSP commands.
3. **Show all commands:** Check this box to include commands from other operating modes. Otherwise, the list contains commands that work in your current mode. Choosing "All" in the category filter does not change this mode filter.

Below those controls, each result gives you a keyboard shortcut and a short description of its command. To run the first result, press `Enter` from the search box. To run another result, select it and press `Enter`.

## Tips

- If you are browsing, start with "All" in the category filter. Choose a category once you know roughly what you are looking for.
- If a search does not find a command you expect, check whether the category filter is set to "All."
- Browse the categories to discover commands and shortcuts you have not used before.
