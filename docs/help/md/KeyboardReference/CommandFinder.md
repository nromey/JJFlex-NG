# Command Finder

Use the Command Finder to find and run keyboard commands in JJ Flexible Radio Access. Its searchable list includes every keyboard command, so you can discover commands or look up a shortcut you have forgotten.

## Opening Command Finder

Press `Ctrl+/` from anywhere in the application to open the Command Finder dialog. Focus will start in the search box, ready for you to type the command you want.

## How It Works

Use these three controls to choose which commands appear in the list:

1. The **Category filter** combo box narrows the list to a category, such as Tuning, digital signal processing (DSP), Audio, or Slices. Select "All" to include every category.
2. Type a word or phrase in the **Search box** to filter commands within the selected category. For example, select DSP and type "noise" to find noise-related DSP commands.
3. The **Show all commands** checkbox includes commands from other operating modes. When it is unchecked, the list includes commands that work in your current mode. Selecting "All" in the category filter does not change this mode filter.

Each entry in the command list gives the keyboard shortcut and a short description of the command. Press `Enter` from the search box to run the first result. To run another command, select its result and press `Enter`.

## Tips

- If you want to browse the available commands, start with "All" in the category filter. Choose a specific category once you know what you want to find.
- If a command you expect is missing, check that the category filter is set to "All." The search applies only to the selected category.
- Browse the categories to learn which commands the application offers.
