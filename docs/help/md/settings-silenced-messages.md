# Messages You Have Silenced

Some of the messages JJ Flexible shows you offer a **Don't show this again** checkbox. Tick it, and that message stops appearing.

Every message you silence that way is kept on a list, by name, with the date you silenced it. You can bring any of them back at any time, one at a time or all at once. Nothing you silence is ever lost for good.

## Where to Find the List

Open **Tools > Settings** and go to the **Notifications** tab. Near the bottom you will find a section called **Messages You Have Silenced**. It tells you how many messages are currently silenced, and a **Review silenced messages** button opens the list.

If nothing is silenced, the section says so and the button is unavailable — there is nothing to review.

## Reading the List

Each line in the list is one silenced message, and the line tells you the whole story: what the message was, and when you silenced it. The most recently silenced message is at the top, because that is usually the one somebody has come looking for.

Arrow up and down the list to hear each one.

## Bringing a Message Back

Choose a message in the list and press **Show this again**. That message will appear again the next time the situation that raises it comes around — exactly as it did before you silenced it.

There is also **Show all of them again**, which brings back everything on the list in one go. It is there for when you want a clean slate. If you only want one message back, choose it in the list instead — restoring everything also restores the messages you silenced on purpose and were glad to be rid of.

Either way, JJ Flexible tells you what it just did, and the same words stay on screen underneath the list so you can find them again.

## What Kinds of Messages End Up Here

Anything that offered you a **Don't show this again** or **Don't ask me this again** checkbox. Today that includes:

- The suggestion to set up SmartLink on this computer.
- The offer to register a particular radio with SmartLink.
- The notice that a routine firmware update is available for a radio. Important firmware releases never offer the checkbox — those keep asking on purpose.
- The explanation shown before turning on remote access to a radio you cannot physically get to.
- The reminder on the way out that something expensive is still running.

Messages that report what actually happened — receipts, errors, safety warnings — never offer the checkbox, so they can never end up here.

## A Note on Wording Changes

If the words of a message change in a later release, that message comes back even though you silenced the older version. That is deliberate. Agreeing to stop seeing one explanation is not the same as agreeing to stop hearing about a new one.
