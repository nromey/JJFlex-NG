- **The profile comparison report no longer freezes the window while it works** — it loads your stored global and TX profiles on the radio in turn to compare them, which takes a minute or two, and until now the whole app sat silent and unresponsive for that long, which sounds exactly like a crash. It now works in the background and tells you which profile it is loading as it goes. When it starts, it tells you which kinds of profile it's about to load. If there's nothing to compare, or the radio's list never arrived, it says that instead and leaves the radio alone. When it's done, the report opens and you hear where it was saved, the same as before.
- **The comparison report and the full restore capture can't run on top of each other any more** — both of them load stored profiles and then put your original ones back, and two of them running at once would each put the radio back on the wrong one. Whichever you start second now tells you straight away that a profile walk is already running, even if you press it a split second after the first.
- **Keying up stops a profile walk, and it tells you where it left the radio** — if you transmit while either report is loading profiles, it stops loading them straight away. It doesn't put your own profile back, because that would change your transmit settings while you're on the air. Instead it tells you the last profile it sent to the radio and which of yours it didn't put back, and the saved file says the same, so you can reload yours from the Radio menu when you're done.
- **Neither report will start while you're transmitting, if it would load profiles** — they ask you to unkey first, and say which kinds of profile they'd load. If a report wouldn't load anything on this radio, it just writes the report. The new sentences you'll hear from these reports are first drafts and may change.
