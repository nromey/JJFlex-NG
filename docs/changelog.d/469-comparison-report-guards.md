- **The profile comparison report no longer freezes the window while it works** — When JJ Flexible Radio Access is processing profiles for comparison, it loads your radio's stored global and TX profiles. This process can take some time, so the application now lets you know that things are happening. If there's nothing to compare, or the radio's list never arrived, the application will notify you and it will then leave the radio's profiles alone. When done, the report opens. The restore capture function follows the same process.
- **Keying up stops a profile walk** — if you transmit while either report is loading profiles, it stops loading them straight away. It doesn't put your own profile back, because that would change your transmit settings while you're on the air. Instead it tells you that your profile may not be the one you started with, so you can load it again from Profiles in the Radio menu when you're done.
