- **The profile comparison report no longer freezes the window while it works** — it loads each of your stored profiles on the radio in turn to compare them, which takes a minute or two, and until now the whole app sat silent and unresponsive for that long, which sounds exactly like a crash. It now works in the background and tells you which profile it is loading as it goes. When it's done, the report opens and you hear where it was saved, the same as before.
- **The comparison report and the full restore capture can't run on top of each other any more** — both of them load every stored profile and then put your original ones back, and two of them running at once would each put the radio back on the wrong one. Before, the restore capture waited its turn but the comparison report didn't. Now whichever you start second tells you a profile walk is already running.
- **The comparison report won't start while you're transmitting** — loading a profile changes power, filters and antennas, so like the restore capture, it now asks you to unkey first. The new sentences you'll hear from this report are first drafts and may change.
