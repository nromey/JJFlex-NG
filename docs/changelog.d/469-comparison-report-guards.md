- **The profile comparison report no longer freezes the window while it works** — it loads your stored global and TX profiles on the radio in turn to compare them, which takes a minute or two, and until now the whole app sat silent and unresponsive for that long, which sounds exactly like a crash. It now works in the background and tells you which profile it is loading as it goes. When it starts, it tells you which kinds of profile it's about to load, or that it won't load any, if there's nothing to compare. When it's done, the report opens and you hear where it was saved, the same as before.
- **The comparison report and the full restore capture can't run on top of each other any more** — both of them load stored profiles and then put your original ones back, and two of them running at once would each put the radio back on the wrong one. Whichever you start second now tells you straight away that a profile walk is already running, even if you press it a split second after the first.
- **Keying up stops a profile walk** — if you transmit while either report is loading profiles, it stops loading them, and it doesn't put your own profile back while you're still on the air either, because that would change your transmit settings mid-transmission. It waits for you to unkey (up to a minute) and puts your profile back then. If you're still transmitting after a minute, it leaves the radio where it is and tells you which profile it's on. Either way, the report says it stopped part-way.
- **Neither report will start while you're transmitting, if it would load profiles** — like the restore capture, the comparison report asks you to unkey first. If it wouldn't load anything on this radio, it just writes the report. The new sentences you'll hear from these reports are first drafts and may change.
