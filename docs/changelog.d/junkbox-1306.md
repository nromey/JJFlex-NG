- JJ Flexible no longer refuses to transmit when your operator has no callsign, unless you ask it to. "Require a callsign to transmit" on the License page of Settings turns that check on for everyone using JJ Flexible on this computer; it starts off.
- If you have turned the callsign check on, a refused key now tells you both ways forward: enter your callsign under Radio, Operators, or turn the check off under Tools, Settings, License. In Check your audio, the refusal comes with a "Turn off the callsign check" button right after Start, so you can turn it off and start the check again straight away.
- When your operator has no callsign, JJ Flexible now reminds you once when it starts, and tells you where to enter one, since logging and other features use it. The reminder has a "Don't show this again" box, and it is not shown the first time you set up JJ Flexible, because that already asks for your callsign.
