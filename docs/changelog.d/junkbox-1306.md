- The callsign check in JJ Flexible Radio Access is now optional and off by default. The "Require a callsign to transmit" checkbox under Tools, Settings, License controls the check for all operators using the currently active Windows user account.
- A callsign refusal now explains how to enter a callsign under Radio, Operators or turn the check off under Tools, Settings, License. The Check your audio tool also offers a "Turn off the callsign check" button when Start is refused for a missing callsign.
- The startup reminder in JJ Flexible Radio Access now explains where to enter a missing operator callsign for logging and other callsign features. The reminder has a "Don't show this again" checkbox and does not appear on the launch that creates the first operator.
