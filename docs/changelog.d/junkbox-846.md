- A JJ key layer you leave open no longer follows you into a JJ Flexible dialog. When the dialog takes the keyboard, the layer closes with its closing tone and keeps what you changed, so Tab moves through the dialog and Escape closes it, and nothing on the radio changes behind it. A layer you open inside a dialog still works there, and the key list H opens still leaves the layer open. A few older dialogs don't close the layer yet: it takes none of their keys, and it is still open when you come back.
