- **The JJ key's value layers no longer let a stray letter out the back door** — if you're in the audio layer, or the filter or noise layer, and you press a letter the layer doesn't use, the layer now stays open and tells you so, instead of quietly closing and handing that letter to whatever was behind it. The old behaviour was the sneaky kind: you'd press Z, hear the refusal, and carry on as if you were still in the layer — while the app had already closed it and Home had taken the Z. Escape still closes the layer, Enter still keeps what you did, and everything that isn't a letter or a digit — a real hotkey, push to talk, the bracket keys, Tab — still does what it always did.
- **Typing a number inside a value layer can no longer retune the radio** — pick VOX delay, type 4, 0, 0, Enter, meaning 400 milliseconds, and until now the 4 closed the layer, the digits went to the frequency field, and Enter set 400 kilohertz. Digits are now caught inside the layer and refused out loud. Typing a value in a layer is a feature on the list, not a thing that half-works today.
- **What you hear for an unknown letter or a digit in a layer** — at chatty verbosity, it is the layer's own answer: the list of letters if you haven't picked anything yet, or "Not a key in the Audio layer. H lists its keys." if you have. A digit gets "A typed number does nothing in the Audio layer. Use the arrows to move the value." Below chatty it's the refusal tone, same as every other refusal. These sentences are first drafts and may change.
