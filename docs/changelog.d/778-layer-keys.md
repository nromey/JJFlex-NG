- **The JJ key's value layers no longer let a stray key out the back door** — if you're in the audio layer, or the filter or noise layer, and you press a key the layer doesn't know, the layer now stays open and tells you so, instead of quietly closing and handing that key to whatever was behind it. The old behaviour was the sneaky kind: you'd press Z, hear the refusal, and carry on as if you were still in the layer — while the app had already closed it and Home had taken the Z. Escape still closes the layer, Enter still keeps what you did, and a key that genuinely is a command elsewhere (Ctrl+F to type a frequency, for instance) still does what it always did.
- **Typing a number inside a value layer can no longer retune the radio** — pick VOX gain, type 1, 4, Enter, meaning a gain of 14, and until now the 1 closed the layer, both digits went to the frequency field, and Enter was a frequency. Those digits are now caught inside the layer and refused out loud. Typing a value in a layer is a feature on the list, not a thing that half-works today.
- **What you hear for an unknown key in a layer** — at chatty verbosity, it is the layer's own answer: the list of letters if you haven't picked anything yet, or "Not a key in the Audio layer. H lists its keys." if you have. A digit gets "A typed number does nothing in the Audio layer. Use the arrows to move the value." Below chatty it's the refusal tone, same as every other refusal. These sentences are first drafts and may change.
