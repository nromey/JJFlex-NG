- **The JJ key's value layers now let go only when you tell them to** — inside the audio, filter or noise layer, the only ways out are Enter, which keeps what you did, Escape, which puts it all back, and the JJ key itself. Any other key the layer doesn't use is refused and the layer stays right where it was: a stray letter, the space bar, and real hotkeys too, like `Ctrl+F` or a band key. Until now those closed the layer on their way past, and "Audio layer closed" got talked over by whatever the key said next, so you'd carry on believing you were still in the layer when you weren't. That was the sneaky part, and it's gone.
- **Push to talk, the transmit lock and the bracket keys still work inside a layer on Home** — with the radio on and you in the Home fields, `Ctrl+Space`, `Shift+Space` and the filter brackets do their usual job and you're still in the layer when they're done, so you can key up while you ride the mic level. Anywhere those keys have never worked, like the Audio Workshop or the full log form, they're now refused inside a layer instead of landing on whatever had focus: you hear the low refusal tone, and at chatty verbosity a few words as well, "No push to talk here." Think of a handheld that beeps when it can't transmit. `Ctrl+Shift` with a bracket, which moves the transmit filter's low edge, and the verbosity cycle work inside a layer on Home and in windows like the Audio Workshop, but not in the full log form, which has never had them. The menus and `F1` help work exactly as before. The new sentences are first drafts and may change.
- **Typing a number inside a value layer can no longer retune the radio** — pick VOX delay, type 4, 0, 0, Enter, meaning 400 milliseconds, and until now the 4 closed the layer, the digits went to the frequency field, and Enter set 400 kilohertz. Digits are now caught inside the layer and refused. Typing a value in a layer is a feature on the list, not a thing that half-works today.
- **What you hear when a layer refuses a key** — at chatty verbosity, the layer's own answer: the list of letters if you haven't picked anything yet, or "Not a key in the Audio layer. Press H to list available keys for this layer." once you have. A digit gets "A typed number does nothing in the Audio layer. Use arrow keys to change the selected number." and, where holding Shift really does give you a finer step, "Shift with the arrows moves it in fine steps." Below chatty it's the refusal tone, same as every other refusal. That last sentence is a first draft and may change.
