<!-- DRAFT (#778c) -->
- **The JJ key's value layers now let go only when you tell them to** — inside the audio, filter or noise layer, the only ways out are Enter, which keeps what you did, Escape, which puts it all back, and the JJ key itself. Any other key the layer doesn't use is refused and the layer stays right where it was: a stray letter, the space bar, Tab (your place on Home stays put while a layer is open), and real hotkeys too, like `Ctrl+F` or a band key. Until now those closed the layer on their way past, and "Audio layer closed" got talked over by whatever the key said next, so you'd carry on believing you were still in the layer when you weren't. That was the sneaky part, and it's gone.
<!-- DRAFT (#778c) -->
- **Push to talk and the transmit lock now work in every window** — `Ctrl+Space` keys the radio and `Shift+Space` locks it from any dialog, the Audio Workshop and Settings included, with a layer open or not, exactly as they do on Home. Until now, in a dialog those two chords pressed whichever button had focus, which is a strange thing for a transmit key to do. If the dialog closes or loses focus while you're holding `Ctrl+Space`, the radio unkeys, every time. One exception, on purpose: in a text box `Shift+Space` still types a space, so a quick capital letter and a space can never lock the transmitter on you. `Ctrl+Space` in a text box still keys. The full log form is the one place that has never had push to talk, and a layer open there still refuses it: the low refusal tone, and at chatty verbosity a few words, "No push to talk here." Think of a handheld that beeps when it can't transmit. `Ctrl+Shift` with a bracket, which moves the transmit filter's low edge, and the verbosity cycle work inside a layer on Home and in windows like the Audio Workshop, but not in the full log form, which has never had them. The menus and `F1` help work exactly as before.
<!-- DRAFT (#778c) -->
- **The bracket filter keys inside a layer are about to change** — today, on Home with the radio on, the brackets still move the filter while a layer is open, and anywhere else a layer refuses them with "That filter key does nothing here." The plan is that inside a layer the brackets belong to the layer, and only the filter layer moves filters with them, so a layer that has nothing to do with filters refuses them everywhere. That lands once the filter layer has bracket keys of its own.
- **Typing a number inside a value layer can no longer retune the radio** — pick VOX delay, type 4, 0, 0, Enter, meaning 400 milliseconds, and until now the 4 closed the layer, the digits went to the frequency field, and Enter set 400 kilohertz. Digits are now caught inside the layer and refused. Typing a value in a layer is a feature on the list, not a thing that half-works today.
- **What you hear when a layer refuses a key** — at chatty verbosity, the layer's own answer: the list of letters if you haven't picked anything yet, or "Not a key in the Audio layer. Press H to list available keys for this layer." once you have. A digit gets "A typed number does nothing in the Audio layer. Use arrow keys to change the selected number." and, where holding Shift really does give you a finer step, "Shift with the arrows moves it in fine steps." Below chatty it's the refusal tone, same as every other refusal. And if you've switched the sounds off, there's no tone to hear, so the words come at every verbosity, Off included: a refused key is never silent. That covers push to talk's "No push to talk here." too.
