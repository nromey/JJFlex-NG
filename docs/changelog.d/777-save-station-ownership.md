- **Saving, creating or deleting a profile on a radio that isn't yours is now refused** — "Save Station Setup to Radio" currently writes the radio's global profile, which is the one everyone who connects to that radio uses. The app now checks radio ownership before allowing the radio to save changes to radio profiles. If you've indicated that the radio doesn't belong to you, or you've never answered the radio ownership question, the application will let you know. It is possible to select any profile that is available on the connected radio, but if you don't own that radio, you cannot save a new profile on that radio.
- **If the app doesn't know yet whether a radio is yours, it tells you where to go to indicate who owns the radio** — This setting can be found in JJ Flexible Radio Access's Settings dialog, under Per-radio settings, "Whose radio is this". This setting matters because the question can go unanswered, disallowing the ability to save and delete profiles even if you own your radio.
