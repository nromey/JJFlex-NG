- The in-app update in JJ Flexible Radio Access now gives you time to answer any prompt to save a log contact or close the application before exiting and applying the update. JJ Flexible alerts you about ongoing meters and recordings before closing to install the new update. Updating JJ Flexible with Check for updates now in the Settings window first applies changes to the radio and any other appropriate settings changes, then exits normally.
