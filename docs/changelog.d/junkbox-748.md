- **Heads up: filter edge mode has new keys.** Pressing a bracket key twice quickly no longer grabs a filter edge, so holding a bracket to widen a filter can't drop you into edge mode by accident any more. Alt+Shift+Left Bracket now grabs the low edge and Alt+Shift+Right Bracket grabs the high edge; press the same one again, or Escape, to let go, and the other one switches edges. While an edge is held, Shift and Ctrl with a bracket leave the filter alone and tell you which edge you're holding, and at Chatty verbosity every step names the held edge. Leaving the mode now says "Filter edge mode off", because nothing you set was thrown away.
