You can now choose which modes Alt+M and Alt+Shift+M step through, and in what order: Settings, Notifications, Mode Cycle. DSB and SAM are there to add if you want them, and leaving a mode out changes only what those two keys visit, never the radio. If your slice is in a mode that is not in the cycle, Alt+M now moves to the nearest mode that is, instead of jumping to one end of the list.
