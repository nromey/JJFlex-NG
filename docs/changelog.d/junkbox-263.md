You can now choose which modes Alt+M and Alt+Shift+M step through, and in what order: Settings, Notifications, Mode Cycle. DSB and SAM are there to add if you want them, and a mode you leave out is still in the Mode menu and on its own key. If your slice is in a mode that is not in the cycle, Alt+M now moves to the nearest mode that is, instead of jumping to one end of the list.
