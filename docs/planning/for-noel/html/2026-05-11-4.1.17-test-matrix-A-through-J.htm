Help-Escape Win32 Hook (2026-04-28 evening commit 09b724c3)

The CHM viewer (hh.exe) is an OS-owned out-of-process window — JJFlex can’t add a normal Escape handler to it. The Win32 keyboard hook in JJFlexWpf/HelpLauncher.cs intercepts Escape when the foreground window’s class is HH Parent (the CHM viewer’s main window) and posts a close message. The hook must NOT swallow Escape in any other context.
