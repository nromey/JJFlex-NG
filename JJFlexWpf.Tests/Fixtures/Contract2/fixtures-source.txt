# Contract 2, protocol version 1: the fixtures, written field by field.
#
# This file is the hand-written record each .bin fixture was assembled from.
# Every value below was written from the protocol description, field by
# field; none was produced by either end's encoder.
#
# Format: "== name.bin" starts a fixture. "msg" starts a message inside it
# (the assembler checks the hand-written length against the bytes that
# follow); "msg nocheck" starts one whose length is deliberately wrong.
# Each other line is one field:
#   u8 / u16 / u32 / u64 N   unsigned, little-endian, decimal or 0x hex
#   f64bits HHHHHHHHHHHHHHHH  an f64 written as its 64 bits, most significant
#                             hex digit first; stored little-endian
#   str "text"               u16 byte count, then the UTF-8 bytes
#   hex AA BB ...            literal bytes, in order
#   f32seq N                 N samples, f32 little-endian, sample i being
#                            (i - 240) / 256, every one exact in f32
#   include name.bin         the bytes of an earlier fixture
# Anything after "#" is a comment.

# ---------------------------------------------------------------------------
# The six worked examples, copied byte for byte as literal hex.
# ---------------------------------------------------------------------------

== heartbeat.bin
msg
hex 02 00 00 00        # length 2
hex 40 00              # type 0x0040 Heartbeat, no payload

== hello-v1.bin
msg
hex 13 00 00 00        # length 19
hex 01 00              # type 0x0001 Hello
hex 01 00              # lowest version 1
hex 01 00              # highest version 1
hex 0B 00              # string length 11
hex 34 2E 31 2E 31 36 2E 32 38 35 39   # "4.1.16.2859"

== open-channel.bin

hex 00                 # no initial values

== close-channel.bin

== set-setting-number.bin
