This build fixes the SmartLink sign-in problem from August 6 - the one
where connecting threw you at a login web page that wouldn't cooperate.

What changed:

- Signing in to SmartLink no longer uses a web page. When JJ Flex needs
  you to sign in, you get a normal dialog: an email box, a password box,
  and a Sign In button. Type, press Enter, done. Works exactly like any
  other dialog with your screen reader.
- There's a Forgot Password button on the same dialog. It emails you a
  reset link at the address you typed.
- If you'd rather use the old web page, the Use Browser Instead button
  brings it back. Accounts with two-factor sign-in go there automatically.
- Once you sign in this way ONE time, the daily nagging should stop for
  good - sign-ins made through the new dialog renew themselves quietly
  in the background, which the old web-page sign-ins never could.

What to test:

1. Start JJ Flex and connect via SmartLink. If it asks you to sign in,
   use the new dialog: email, password, Enter.
2. Confirm the radio connects and audio flows.
3. Close JJ Flex, reopen it, connect again. This time it should NOT ask
   you to sign in at all. That silent second connect is the actual fix -
   please tell Noel whether you got it.
4. If anything asks you to sign in through a web page when you didn't
   choose the browser button, that's a bug - grab the trace and send it.

Known issues:

- The Settings > Radios tab is new in this build (per-radio connection
  settings and radio renaming). Feel free to poke at it, but the main
  event today is the sign-in fix.
