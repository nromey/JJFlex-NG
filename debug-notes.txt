WHAT IS NEW SINCE THE LAST BUILD

This is the first build since 3 October, so there is a lot in it. The
changelog has the full list, under Unreleased. The ones you will notice:

- Push to talk works from inside the app's own windows now. Ctrl+Space
  keys the radio from Settings and other dialogs instead of pressing a
  button.
- In a dialog, Escape unkeys first. Press it again to close the dialog.
- Inside the audio, filter and noise layers, a key the layer doesn't use
  is refused and the layer stays open. Typing a number there no longer
  retunes the radio.
- Saving or deleting a profile on a radio that isn't yours is refused.
  Tell the app whose radio it is in Settings, Per-radio settings.
- Switch Mic Input Back to PC is new on the Radio menu.
- The Memories dialog can change a memory now, not just read one.

KNOWN ISSUES

- Shift+Space just after the high reflected power alarm cuts your
  transmit can lock you straight back on. Press it again to unlock.
- Holding Shift+Space too long can switch the lock on and off several
  times. Tap it.
- In Logging mode, Ctrl+Shift+L doesn't take you back out. Use the Mode
  menu instead.
- Under NVDA, words like "can't" are spoken as "can t".
- These keys have only been checked under NVDA so far. JAWS is next.
